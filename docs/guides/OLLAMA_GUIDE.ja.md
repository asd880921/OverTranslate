# ローカル LLM (Ollama) の導入ガイド

> **Language:** **[繁體中文](OLLAMA_GUIDE.md)** ｜ **[English](OLLAMA_GUIDE.en.md)** ｜ **[简体中文](OLLAMA_GUIDE.zh-Hans.md)** ｜ **日本語 ✓** ｜ **[한국어](OLLAMA_GUIDE.ko.md)**

OverTranslate の **OpenAI** 翻訳サービスは OpenAI API 互換の形式に対応しているため、[Ollama](https://ollama.com/) を使って LLM をローカルで動かせます。ローカルモデルなら API の追加費用はかからず、翻訳する内容が外部のサーバーに送られることもありません。

ここでは `hf.co/tencent/Hy-MT2-7B-GGUF:Q4_K_M`（テンセントが公開している翻訳専用モデル。33 言語の相互翻訳に対応）を例に説明します。

> **必要な環境：** ローカル LLM はパソコンの CPU / GPU を使います。翻訳の速度を考えると、独立したグラフィックスカードを搭載したマシンをおすすめします。
>
> このガイドで使うモデルのファイルサイズは約 4.6 GB、読み込み後は約 5.5 GB を使用します。グラフィックスカードの VRAM は **6 GB 以上、できれば 8 GB 以上**を目安にしてください。実際の使用量は Ollama や入力内容、ほかのアプリの GPU 使用量によって変わります。
>
> VRAM がわずかに足りないだけでも速度は大きく落ちます（モデルの一部が CPU で動くためです）。その場合は、下記のより小さい量子化版に切り替えてください。

## 1. Ollama をインストールする

1. [Ollama の公式サイト](https://ollama.com/download) から、お使いの OS 向けのインストーラーをダウンロードします
2. インストーラーを実行し、既定のオプションのままインストールを完了します

インストール後、Ollama を起動します。Ollama の API アドレスは既定で `http://localhost:11434` です（設定を変更したことがある場合は、実際のアドレスに読み替えてください）。

## 2. モデルをダウンロードする

「コマンド プロンプト」または「PowerShell」を開き、次を実行します。

```
ollama pull hf.co/tencent/Hy-MT2-7B-GGUF:Q4_K_M
```

ダウンロードが終わるまで待ちます（モデルは約 4.6 GB あるため、回線によっては数分かかります）。

> **VRAM が足りない場合**は、`ollama pull` に続く名前を次のいずれかに置き換えて、同じモデルのより小さい版を使ってください。
>
> | モデル名 | ファイルサイズ | 目安 |
> |----------|----------------|------|
> | `hf.co/tencent/Hy-MT2-7B-GGUF:Q4_K_M` | 約 4.6 GB | VRAM 6 GB 以上（本ガイドで使用） |
> | `hf.co/unsloth/Hy-MT2-7B-GGUF:IQ4_XS` | 約 4.2 GB | VRAM 5〜6 GB |
> | `hf.co/unsloth/Hy-MT2-7B-GGUF:Q3_K_M` | 約 3.8 GB | VRAM 4 GB |
>
> 下の 2 つはコミュニティによる再パッケージで、モデル自体は同じものです。小さい版ほどダウンロードも動作も速くなりますが、翻訳品質は少し下がります。

> [Ollama Models](https://ollama.com/search) でほかのモデルを探し、モデル名を差し替えることもできます。
> 思考モードを使わないモデルを選んでください。迷う場合は、このガイドのとおり推奨モデルをそのまま使えば問題ありません。

## 3. OverTranslate 側の設定

1. OverTranslate の設定ページを開き、翻訳サービスで **OpenAI Compatible** を選びます
2. **API アドレス** と **API キー** はどちらも空欄で構いません。アドレスの既定値が Ollama のローカルアドレスで、ローカル実行ならキーも不要です
3. モデル設定は **推奨設定** のままで構いません。このガイドが推奨するモデル `hf.co/tencent/Hy-MT2-7B-GGUF:Q4_K_M` を使い、プロンプトもそれに合わせて書かれています
4. 設定ページを閉じれば、ローカル LLM での翻訳を始められます

> **別のモデルを使う場合**は、設定一覧の **追加** からモデル名（先頭の `hf.co/` を含む完全な名前）とそのモデルが求めるプロンプトを入力し、保存して選択します。1 つの設定はひとまとまりです。モデル名、Temperature、そして **自動** と **言語を指定** それぞれの System / User プロンプト —— 設定を切り替えると、これらがまとめて切り替わります。

> **プロンプトと Temperature について：** 既定のプロンプトは OverTranslate の表示言語に合わせて切り替わり、このガイドの推奨モデル向けに調整済みです。User プロンプトのみを送り System プロンプトは送りませんが、これはそのモデルの公式ドキュメントが示す形式によるものです。モデルごとに求められる形は異なり、どちらか一方が入っていれば構いません。詳細パラメーター（Temperature `0.7`、Top P `0.6`、Seed `42`）は既定ですべて有効で、値は推奨モデルの公式ドキュメントが示す推奨値です。Seed を固定しているため、同じ原文からは毎回同じ訳文が得られます。
