# 로컬 LLM (Ollama) 설치 안내

> **Language:** **[繁體中文](OLLAMA_GUIDE.md)** ｜ **[English](OLLAMA_GUIDE.en.md)** ｜ **[简体中文](OLLAMA_GUIDE.zh-Hans.md)** ｜ **[日本語](OLLAMA_GUIDE.ja.md)** ｜ **한국어 ✓**

OverTranslate의 **OpenAI** 번역 서비스는 OpenAI API 호환 형식을 지원하므로, [Ollama](https://ollama.com/)로 LLM을 내 PC에서 실행할 수 있습니다. 로컬 모델을 쓰면 API 비용이 따로 들지 않고, 번역하는 내용이 외부 서버로 전송되지도 않습니다.

아래에서는 `hf.co/tencent/Hy-MT2-7B-GGUF:Q4_K_M`(텐센트가 공개한 번역 전용 모델로, 33개 언어 간 번역을 지원합니다)를 예로 설명합니다.

> **필요 사양:** 로컬 LLM은 PC의 CPU / GPU 자원을 사용합니다. 번역 속도를 생각하면 외장 그래픽 카드가 있는 PC를 권장합니다.
>
> 이 안내에서 사용하는 모델 파일은 약 4.6 GB이고, 불러온 뒤에는 약 5.5 GB를 사용합니다. 그래픽 카드의 VRAM은 **최소 6 GB, 가능하면 8 GB 이상**을 권장합니다. 실제 사용량은 Ollama와 입력 내용, 다른 프로그램의 GPU 사용량에 따라 달라집니다.
>
> VRAM이 조금만 모자라도 속도가 크게 떨어집니다(모델의 일부가 CPU에서 실행되기 때문입니다). 이럴 때는 아래의 더 작은 양자화 버전으로 바꾸세요.

## 1. Ollama 설치

1. [Ollama 공식 사이트](https://ollama.com/download)에서 사용 중인 운영체제용 설치 파일을 내려받습니다
2. 설치 파일을 실행하고 기본 옵션 그대로 설치를 마칩니다

설치가 끝나면 Ollama를 실행합니다. Ollama의 API 주소는 기본값이 `http://localhost:11434`입니다(관련 설정을 바꾼 적이 있다면 실제 주소를 사용하세요).

## 2. 모델 내려받기

‘명령 프롬프트’ 또는 ‘PowerShell’을 열고 다음을 입력합니다.

```
ollama pull hf.co/tencent/Hy-MT2-7B-GGUF:Q4_K_M
```

내려받기가 끝날 때까지 기다립니다(모델이 약 4.6 GB이므로 회선에 따라 몇 분 걸립니다).

> **VRAM이 부족하다면** `ollama pull` 뒤의 이름을 아래 중 하나로 바꿔 같은 모델의 더 작은 버전을 사용하세요.
>
> | 모델 이름 | 파일 크기 | 권장 |
> |-----------|-----------|------|
> | `hf.co/tencent/Hy-MT2-7B-GGUF:Q4_K_M` | 약 4.6 GB | VRAM 6 GB 이상(이 안내에서 사용) |
> | `hf.co/unsloth/Hy-MT2-7B-GGUF:IQ4_XS` | 약 4.2 GB | VRAM 5~6 GB |
> | `hf.co/unsloth/Hy-MT2-7B-GGUF:Q3_K_M` | 약 3.8 GB | VRAM 4 GB |
>
> 아래 두 개는 커뮤니티가 다시 패키징한 것으로 모델 자체는 같습니다. 작은 버전일수록 내려받기와 실행이 빠르지만, 번역 품질은 조금 낮아집니다.

> [Ollama Models](https://ollama.com/search)에서 다른 모델을 찾아 모델 이름을 바꿔도 됩니다.
> 사고 모드를 쓰지 않는 모델을 고르세요. 무엇을 골라야 할지 모르겠다면 이 안내대로 권장 모델을 그대로 쓰면 됩니다.

## 3. OverTranslate에서 설정

1. OverTranslate 설정 페이지를 열고 번역 서비스에서 **OpenAI Compatible**을 선택합니다
2. **API 주소**와 **API 키**는 모두 비워 두어도 됩니다. 주소의 기본값이 Ollama의 로컬 주소이고, 로컬 실행에는 키도 필요 없습니다
3. 모델 설정은 **권장 설정** 그대로 두면 됩니다. 이 안내가 권장하는 모델 `hf.co/tencent/Hy-MT2-7B-GGUF:Q4_K_M`을 사용하며 프롬프트도 그 모델에 맞춰 쓰여 있습니다
4. 설정 페이지를 닫으면 로컬 LLM으로 번역을 시작할 수 있습니다

> **다른 모델을 쓰려면** 설정 목록에서 **추가**를 눌러 모델 이름(`hf.co/`까지 포함한 전체 이름)과 그 모델이 요구하는 프롬프트를 입력하고, 저장한 뒤 선택하세요. 설정 하나가 한 묶음입니다. 모델 이름, Temperature, 그리고 **자동**과 **언어 지정** 각각의 System / User 프롬프트가 함께 바뀝니다.

> **프롬프트와 Temperature:** 기본 프롬프트는 OverTranslate의 인터페이스 언어에 맞춰 바뀌며, 이 안내에서 권장하는 모델에 맞게 조정되어 있습니다. System 프롬프트 없이 User 프롬프트만 보내는데, 이는 해당 모델 공식 문서가 제시하는 형식입니다. 모델마다 요구하는 형태가 다르므로 둘 중 하나만 채워도 됩니다. 고급 매개변수(Temperature `0.7`, Top P `0.6`, Seed `42`)는 기본으로 모두 켜져 있으며, 값은 권장 모델 공식 문서가 제시하는 권장값입니다. Seed가 고정되어 있어 같은 원문은 매번 같은 번역이 나옵니다.
