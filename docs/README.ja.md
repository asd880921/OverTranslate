## 翻訳機能

OverTranslate には 5 つの翻訳機能があり、その場に合ったものをすぐ選べます。

- **[キャプチャ翻訳](#キャプチャ翻訳)** — 画面の範囲を選ぶと、文字を読み取って訳文をその場に重ねて表示します
- **[リアルタイム翻訳](#リアルタイム翻訳)** — 動画やゲーム画面の指定した範囲を翻訳し続け、訳文を元の位置に表示します
- **[クイック辞書](#クイック辞書)** — テキストを選ぶと小さな翻訳ウィンドウが開きます。ピン留めして出したままにもできます
- **[クイック翻訳](#クイック翻訳)** — テキストを選んでショートカットキーを押すと、その場で訳文に置き換わります
- **[テキスト翻訳](#テキスト翻訳)** — 入力・言語の入れ替え・読み上げに対応した、通常の翻訳ウィンドウです

## キャプチャ翻訳

**メインウィンドウは閉じてタスクトレイに常駐できる**ので、ふだんは開いたままにしておく必要はありません。  
翻訳したいときにショートカットキー（既定 Ctrl + Alt + A）を押し、翻訳したい範囲を選ぶだけです。
> Web ページ、PDF、画像、動画、ゲームの画面など、文字を直接選択できない場面で使えます。

## リアルタイム翻訳

**動画の字幕やゲーム画面**など、翻訳し続けたい場面に向いています。範囲を選ぶと画面の内容を読み取り続け、  
文字が変わるたびに訳文を更新して元の位置に表示します。

取り込み方法は **画面全体** と **ウィンドウ指定** の 2 つです。  
画面全体は Windows 11 24H2 以降、ウィンドウ指定は Windows 10 1903 以降が必要です。

> 遅延の少ない Microsoft、DeepL、OpenAI の利用をおすすめします。  

> 訳文の文字色・背景色・背景の不透明度は自由に変えられます。**背景になじませる** と **原文の文字色を使う** をオンにすると、訳文が元の画面の配色になじみます。

![リアルタイム翻訳のプレビュー](images/即時翻譯視窗預覽_en.png)

### 翻訳ブロックのモード（範囲選択）

> リアルタイム翻訳中はショートカットキー（既定 Ctrl + Alt + S）で一時停止・再開できます。  
> 翻訳が要らない場面や、原文をそのまま見たいときに一時停止し、あとで再開すれば、リアルタイム翻訳を終了する必要はありません。

翻訳ブロックには **字幕 / セリフ** と **ゲーム / UI** の 2 つのモードがあります。
**字幕 / セリフ**：動画の字幕やゲームのセリフなど、文字の位置が決まっている場面向けです（1 つを推奨）。

## クイック辞書
> ショートカットキー（既定 `Ctrl + Alt + Q`）で、どの画面からでも開けます。

テキストを選んでショートカットキーを押すと、そのまま読み込んで翻訳します。何も選んでいないときは、直接入力もできます。  
ほかのウィンドウに切り替えると閉じます。出したままにしたいときはピン留めしてください。

![クイック辞書](images/選詞翻譯.png)

---

## クイック翻訳
> ショートカットキー（既定 `Ctrl + Alt + E`）。翻訳してもウィンドウは開きません。

テキストを選んでショートカットキーを押すと、訳文がそのまま貼り付けられて原文と置き換わります（文字を入力できる欄でのみ動作し、入力欄以外には貼り付けられません）。

![クイック翻訳](images/快速翻譯.png)

---

## テキスト翻訳

**入力するだけで翻訳**でき、翻訳元と翻訳先の言語はすぐ入れ替えられます。  
音声合成（TTS）を内蔵しており、原文と訳文のどちらも読み上げられます。

![テキスト翻訳のプレビュー](images/翻譯視窗預覽_en.png)

## 設定

![設定ページ](images/設定頁_en.png)

| 設定項目 | 説明 |
|----------|------|
| 表示言語 | 繁體中文 / 简体中文 / English / 日本語 / 한국어。切り替えるとすぐ反映されます（初回起動時は Windows の表示言語に従います） |
| キャプチャ翻訳（ショートカットキー） | **キャプチャ翻訳** を始めるショートカットキー（変更可、既定 `Ctrl + Alt + A`） |
| 翻訳ウィンドウを開く（ショートカットキー） | メインウィンドウを前回のページで呼び出します（既定 `Ctrl + Alt + W`）。リアルタイム翻訳中は、フローティングバーを最前面に移動します |
| 一時停止 / 再開（ショートカットキー） | **リアルタイム翻訳** を一時停止・再開します（既定 `Ctrl + Alt + S`）。リアルタイム翻訳中のみ使え、原文を確認したいときに便利です |
| クイック辞書（ショートカットキー） | **クイック辞書** のウィンドウを開きます（既定 `Ctrl + Alt + Q`）。テキストを選択していれば自動で読み込んで翻訳します |
| クイック翻訳（ショートカットキー） | 選択中のテキストを訳文に置き換えます（既定 `Ctrl + Alt + E`）。何も選択していなければ何も起きません |
| 自動翻訳 | **キャプチャ翻訳** で範囲を選び終えた時点で **すぐ翻訳** し、クリックの手間をなくします（既定はオフ） |
| スタートアップ | Windows の起動時に自動で開始します |
| スクリーンショットの保存 | キャプチャのたびに自動で保存します。保存先は変更できます（既定はオフ） |
| 翻訳元の言語 | **キャプチャ翻訳** と **テキスト翻訳** の原文の言語（既定は Auto）。リアルタイム翻訳の翻訳元は別に設定します |
| 翻訳サービスの設定 | キーやエンドポイントが必要なサービスを設定します。OpenAI では API アドレス、モデル名、プロンプト、Temperature を設定できます |
| テーマ | ライト / ダーク |
| アプリのログ | アプリの情報をより詳しく記録します。問題を調べるときだけの利用をおすすめします（既定はオフ） |

> ショートカットキーは組み合わせだけでなく、単独のキーにもできます。F1 ~ F12、マウスの中ボタン／サイドボタン、ゲームパッドのボタンが使えます。

> ログはお使いの PC にのみ保存され、自動で送信されることはありません。**アプリのログ** をオンにしたときの詳細な情報も、同じく PC の中に残るだけです。  
> 問題を報告するときは、設定ページの **診断情報を書き出してアップロード** を押してください。そのままアップロードされ、報告コードが表示されます（開発者に伝えると照合が早く済みます）。

### 翻訳 API

> DeepL と OpenAI 以外は、ダウンロードすればそのまま使えます。

| サービス | 説明 |
|------|------|
| Google 翻訳（RPC） | 新しい RPC インターフェース |
| Google 翻訳（Web） | 従来の Web インターフェース |
| Bing 翻訳 | 訳文の品質が高い |
| Microsoft 翻訳 | **（既定）** 安定していて応答も速い |
| DeepL | DeepL の公式サイトで登録して API キーを取得する必要があります |
| OpenAI | OpenAI API 互換の形式に対応。ローカル LLM の利用がおすすめで、[Ollama](guides/OLLAMA_GUIDE.ja.md) なら手軽に導入できます。プロンプトと Temperature は変更できます |
  
**自動バックアップ**の仕組みがあります（**キャプチャ翻訳** と **リアルタイム翻訳** で働きます）。  
あるサービスが使えなかったり応答が遅かったりすると、使える別の翻訳 API へ自動で切り替わり、実際に使われたエンジンがツールバーに表示されます。
![バックアップ](images/備援.png)

> **OpenAI** の利用中はバックアップに切り替わりません。

### OpenAI の設定

![OpenAI](images/OpenAI.png)

| 項目 | 説明 |
|------|------|
| API アドレス | 空欄なら `http://localhost:11434/v1`（Ollama のローカル既定アドレス）を使います |
| モデル名 | 空欄なら `translategemma:4b` を使います |
| プロンプト | 空欄なら組み込みのプロンプトを使います。下のパラメーターでその回の言語を差し込めます |
| Temperature | **詳細** にあります。出力のばらつきに影響し、範囲は 0.0 ~ 2.0（既定 0） |

プロンプトで使えるパラメーター（設定ページの **使用できるパラメーター** にも説明と例があります）：

| パラメーター | 説明 | 例 |
|------|------|------|
| `{source_name}` | 翻訳元の言語名 | 英語 |
| `{source_code}` | 翻訳元の言語コード | en |
| `{target_name}` | 翻訳先の言語名 | 日本語 |
| `{target_code}` | 翻訳先の言語コード | ja |

> 組み込みのプロンプトは言語名だけを使います。言語コードのパラメーターはモデルに合わせて組み合わせてください。例：`{target_name} (target_code)` -> `Japanese (ja)`。
> 
> Temperature のチェックを外すと **このパラメーターを送信しません**。対応状況や推奨値はモデルや API によって異なるため、モデルのドキュメントが送信しないよう勧めている場合はチェックを外してください。0 で出力がおかしいときは、モデルの推奨に従って上げてみてください。0.1 から少しずつ調整することをおすすめします。

### 多言語 OCR

OCR は RapidOcrNet と ONNX モデルで処理し、言語に応じてモデルが自動で切り替わります。OCR エンジンを手で選ぶ必要はありません。

| 認識する言語 | 認識モデル（rec） |
|----------|----------------|
| **英語 / 中国語（簡体字・繁体字）/ 日本語** | PP-OCRv6 汎用認識モデル（`PP-OCRv6_small_rec`）。1 つのモデルで中国語・英語・日本語と各種ラテン文字に対応し、よくある中英混在も読めます |
| **韓国語** | PP-OCRv5 韓国語認識モデル（`korean_PP-OCRv5_rec`）。PP-OCRv6 の汎用モデルが覆っていない韓国語の文字を補います |

**文字検出モデル**（`PP-OCRv6_det_tiny`）と**方向分類モデル**（`cls`）はすべての言語で共通で、切り替わるのは認識モデルだけです。  
OCR は最初から最後までお使いの PC の CPU で動き、画像が外部のサービスに送られることはありません。

## 動作環境

- **OS**：Windows 10 / 11
- **ランタイム**：必要なものはインストーラーに含まれているため、.NET ランタイムを別途入れる必要はありません

次の翻訳サービスを使う場合は、別途用意が必要です。

- **DeepL**：[DeepL 公式サイト](https://www.deepl.com/pro-api) で API キーを取得してください
- **OpenAI**：OpenAI API 互換のサービスをご自身で用意してください。ローカル LLM の構築方法は [Ollama の導入ガイド](guides/OLLAMA_GUIDE.ja.md) を参照してください
