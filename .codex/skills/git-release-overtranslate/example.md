## ◆ 新增多語系語言
- 新增簡體中文、日文、韓文介面語言支援

## ◆ 截圖翻譯：優化
- 現在會依照辨識結果，將上下相關語句自動合併分組後再進行翻譯，減少因文字被拆分而造成的語意斷句問題
- 辨識失敗時會自動退回編輯框模式，可直接重新調整範圍，不再需要重新開啟截圖翻譯

## ◆ 截圖翻譯：新功能
- 新增 `標記` 功能：可在截圖畫面上進行標記繪製
- 新增 `複製文字 / 複製譯文` 功能：可直接辨識原文文字並複製至剪貼簿，(不需要執行 `翻譯` 功能)
- 新增 `偵錯輔助` 功能：可顯示文字辨識範圍與文字組合範圍，方便確認目前的辨識與分組結果

## ◆ 設定頁：OpenAI 提示詞
- 新增提示詞儲存功能，最多可儲存 5 組提示詞並快速切換
- 新增預設提示詞選項，可隨時切換回應用提供的預設設定

## ◆ 快速翻譯
- 新增獨立翻譯設定：可設置來源與目標語言，不再與其他翻譯功能共用設定

## ◇ 其他改善
- 主視窗標題列新增釘選按鈕，可讓視窗保持在最上層
- 優化翻譯服務遇到字數上限時可能發生的錯誤問題
- 截圖翻譯發生異常時，現在仍可透過 `Esc` 取消截圖；開啟工作管理員時也會自動讓出最上層，避免畫面卡住
- 更新應用程式圖示
